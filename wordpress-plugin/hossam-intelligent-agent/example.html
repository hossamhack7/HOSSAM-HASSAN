🤖 إضافة المساعد الذكي لحسام لووردبريس

نظرة عامة

هذه الإضافة تربط موقع WordPress الخاص بك بنظام المساعد الذكي الخلفي لحسام، مما يوفر ميزات مدعومة بالذكاء الاصطناعي لزوار موقعك.

الميزات الرئيسية

💬 واجهة محادثة تفاعلية

أضف واجهة محادثة ذكية إلى أي صفحة أو منشور باستخدام كود مختصر بسيط.

⚙️ لوحة تحكم سهلة

واجهة إدارية بسيطة لتكوين الاتصال بالخادم الخلفي وإدارة الإعدادات.

🌍 دعم متعدد اللغات

يدعم اللغة العربية والإنجليزية مع إمكانية إضافة لغات أخرى.

📱 تصميم متجاوب

يعمل بشكل مثالي على جميع الأجهزة والشاشات.

🔒 آمان متقدم

يستخدم أفضل ممارسات الأمان في WordPress مع التحقق من الهوية.

🚀 أداء سريع

تقنية AJAX للتفاعل السريع دون إعادة تحميل الصفحة.

التثبيت والإعداد

  1. ارفع مجلد الإضافة إلى /wp-content/plugins/
  2. فعّل الإضافة من لوحة تحكم WordPress
  3. اذهب إلى الإعدادات > المساعد الذكي
  4. أدخل رابط خادم المساعد الذكي الخلفي
  5. احفظ الإعدادات

كيفية الاستخدام

استخدم الكود المختصر التالي في أي صفحة أو منشور:

[hia_chat]

أو مع خيارات متقدمة:

[hia_chat title="مساعد ذكي" height="500px" width="100%"]

مثال على واجهة المحادثة

💬 تحدث مع المساعد الذكي

مرحبا! كيف يمكنني مساعدتك اليوم؟
أريد معرفة المزيد عن هذا الموقع
بالطبع! هذا موقع يستخدم المساعد الذكي لحسام لتوفير تجربة تفاعلية مميزة للزوار. يمكنني مساعدتك في الإجابة على أسئلتك وتقديم المعلومات التي تحتاجها.

متطلبات النظام

  • WordPress 5.0 أو أحدث
  • PHP 7.4 أو أحدث
  • خادم المساعد الذكي الخلفي (Python Flask)

التكوين المتقدم

يمكن تخصيص الإضافة من خلال:

  • تعديل ملفات CSS في مجلد assets/css/
  • إضافة وظائف جديدة في الملف الرئيسي للإضافة
  • إنشاء ملفات ترجمة جديدة في مجلد languages/
