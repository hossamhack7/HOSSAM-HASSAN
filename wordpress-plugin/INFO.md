# Hossam Intelligent Agent WordPress Plugin

إضافة المساعد الذكي لحسام - WordPress Plugin

## ملفات الإضافة (Plugin Files)

```
hossam-intelligent-agent/
├── hossam-intelligent-agent.php    # الملف الرئيسي للإضافة
├── assets/                         # الملفات الإضافية
│   ├── css/
│   │   ├── frontend.css           # تنسيقات الواجهة الأمامية
│   │   └── admin.css              # تنسيقات لوحة التحكم
│   └── js/
│       └── frontend.js            # وظائف JavaScript
├── includes/
│   └── uninstall.php              # ملف إلغاء التثبيت
├── languages/                     # ملفات الترجمة
│   └── hossam-intelligent-agent-ar.po
├── README.md                      # الوثائق التقنية
├── INSTALL.md                     # دليل التثبيت
└── example.html                   # صفحة المثال
```

## الاستخدام السريع (Quick Start)

1. **التثبيت:** ارفع الإضافة إلى WordPress
2. **التفعيل:** فعّل الإضافة من لوحة التحكم
3. **الإعداد:** اذهب إلى الإعدادات > المساعد الذكي
4. **الاستخدام:** أضف `[hia_chat]` إلى أي صفحة
