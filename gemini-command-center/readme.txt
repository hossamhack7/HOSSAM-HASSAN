== Description ==

Gemini Command Center is a revolutionary WordPress plugin that brings the power of Google's Gemini AI directly into your WordPress dashboard. This comprehensive management suite provides intelligent automation, advanced SEO tools, content generation, and strategic insights to supercharge your website's performance.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/gemini-command-center` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Navigate to the Gemini Command Center menu in your WordPress admin.
4. Enter your Google Gemini API key in the settings.
5. Follow the onboarding tour to get started with key features.

== Frequently Asked Questions ==

= Do I need a Google Gemini API key? =

Yes, you need a Google Gemini API key to use the AI features. You can obtain one from the Google AI Studio. The plugin includes a connection test feature to verify your API key is working correctly.

= Is my data secure? =

Absolutely. The plugin follows WordPress security best practices and never stores sensitive data unnecessarily. All API communications are encrypted, and backups are stored in protected directories.

= Can I use this plugin on multiple sites? =

Yes, but each site requires its own API key and configuration. The plugin includes export/import functionality to easily migrate settings between sites.

= Will this slow down my website? =

No. The plugin is designed for performance with conditional loading, caching, and efficient database usage. Frontend features only load when needed.

= Can I disable specific modules? =

Yes, all major modules can be enabled or disabled individually through the settings panel. This allows you to use only the features you need.

= How does the A/B testing work? =

The A/B testing feature creates variants of your post titles and serves them to different visitors. It tracks impressions and clicks to determine the winning variant automatically.
